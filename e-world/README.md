# E起看世界 · 可点击演示版

此版本用于青管赛流程展示，使用本地规则和已收录资料，不连接大模型，不包含任何 API 密钥。

## 评委体验顺序

1. 点击“博士生联培与实习”，比较求是飞鹰、CSC博士联培和国际组织实习。
2. 点击“大一大二探索方向”，查看低年级探索、NIE教学实习及未来深造路径。
3. 点开项目，查看匿名反馈、申请准备与来源；勾选两个或三个项目进行比较。
4. 进入“资助与会议目录”，检索AERA等会议，了解雏鹰资助上限与条件。

基础通知截至2026年11月16日，2026年11月22日补充学生反馈与历史去向，为精选案例，不是全校实时全量目录。历史案例不代表正在招生，匹配不代表符合申请资格。原始内部文件、学生名单、API密钥和访问码不随站点公开。

## 本地查看

在本目录运行 `python3 -m http.server 8766 --bind 127.0.0.1`，再用浏览器打开 http://127.0.0.1:8766/ 。

GitHub Pages 只托管本目录内容，不需要后端或付费服务。网页链接在国内网络的可达性需由实际网络验证。
